## 📦 Packages

| Package | Use it for |
|---|---|
| [`val_latex`](https://pub.dev/packages/val_latex) | The engine, in pure Dart: a TeX parser, TeX layout with line breaking and right-to-left math, OpenType math fonts, speech and LaTeX output. Runs on the VM, in Flutter, on servers and on the web. |
| [`val_latex_flutter`](https://pub.dev/packages/val_latex_flutter) | Flutter widgets: `Math.tex` for a formula, `MathText` for text with formulas in it, `MathSpan` for inline math, theming, selection, screen-reader speech, and a drop-in replacement for `flutter_math_fork`. |

## 🐞 Reporting a bug

[Open an issue](https://github.com/useval/val_latex/issues/new) and include:

- **The package and version** — `val_latex` or `val_latex_flutter`, and
  the version from your `pubspec.lock`.
- **Where it runs** — Flutter and Dart versions (`flutter --version`) and
  the platform (Android, iOS, web, macOS, Windows or Linux).
- **The exact LaTeX source** that shows the problem, as a code block.
- **What you expected, and what happened** — a screenshot helps for
  anything visual; the full error for a crash.
- **The smallest code that shows it**, if a widget or option is involved.

Before opening one, please search the
[existing issues](https://github.com/useval/val_latex/issues?q=is%3Aissue);
a 👍 on an existing issue helps us prioritise it.

## 💡 Feature requests and feedback

A missing command, a package you rely on, an output that looks different
from LaTeX, or an idea for the API — open an issue and tell us what you
are trying to do. Formulas from real documents are the most useful
examples.

## 🔒 Security
